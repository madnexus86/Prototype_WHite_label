# X5 Games Prototype (Android)

Минимальный Android-прототип:
- главный экран с приветствием и `clientId` вида `X5_1` ... `X5_100`;
- идентификатор существует в памяти процесса и не записывается на диск;
- WebView открывает `https://beeline.ru/games/games-page/?clientId=<clientId>`;
- кнопка «← Назад» и системная кнопка Back возвращают на главный экран.

## Сборка APK через GitHub Actions

В репозитории уже добавлен workflow `.github/workflows/build-apk.yml`.

1. Создайте пустой репозиторий на GitHub.
2. Загрузите туда содержимое этой папки (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** и запустите **Build Android APK** (или сделайте push в ветку `main`).
4. Когда сборка завершится успешно, откройте запуск workflow и скачайте артефакт `X5GamesPrototype-debug-apk`.
5. Распакуйте артефакт: внутри будет `app-debug.apk`. Перенесите его на Android-телефон и установите. При необходимости разрешите установку из этого источника.

Для локальной сборки нужны JDK 17, Android SDK platform 35 и Gradle 8.9+.

## Примечание про случайный идентификатор

Каждый новый запуск процесса генерирует случайное число от 1 до 100. Поскольку предыдущий ID намеренно нигде не хранится, теоретически число может совпасть с ID предыдущего запуска.


## Скрытие шапки сайта в WebView

В версии прототипа 1.1 приложение пытается скрыть шапку сайта средствами WebView:
- после загрузки внедряется JavaScript/CSS;
- скрываются распространённые элементы шапки (`header`, `role=banner`, классы/идентификаторы `header`, `navbar` и похожие);
- `MutationObserver` повторяет проверку, если сайт дорисовывает шапку после первоначальной загрузки.

**Ограничение:** точную DOM-структуру сайта не удалось проверить из среды сборки. Поэтому это эвристический вариант, а не гарантированная интеграция. На телефоне нужно проверить, исчезли ли логотип, меню и помощь и не скрылись ли лишние элементы. Если шапка останется, понадобится определить её CSS-селекторы через инструменты разработчика и добавить их в `HIDE_SITE_HEADER_SCRIPT`.
